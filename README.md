# Геокодирование адресов Тюмени
## Проект по работе с API Яндекса
Берем адреса из CSV, обращаемся к Геокодеру Яндекс Карт и собираем ответ в таблицу. Не только получаем координаты, но и оставить рядом исходный адрес

## Что происходит при запуске

- Из `data/input/addresses.csv` читается `object_id` и `address`.
- Для каждого заполненого адреса отправляется HTTP-запрос. Далее, мы извлекаем найденный адрес, координаты, город, тип объекта и точность геокодирования
- Ошибки запроса выводятся в консоль. Из-за одного неудачного ответа обработка остальных адресов не прекращается
- Результат получает статус `accepted`, `review` или `rejected` и записывается в `data/output/geocoded.csv`

`accepted` ставится для дома в Тюмени с точностью `exact`. Если ответ относится к дому в Тюмени, но точность ниже (`number`, `near` и.т.д.), попадает в `review`. Остальные ответы `rejected`

На текущем наборе из 29 адресов получилось 28 записей со статусом `accepted` и одна со статусом `review`

## Как запустить

Из корня проекта установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте `.env` по образцу `.env.example` и укажите свой ключ в переменной `YANDEX_GEOCODER`. Затем запустите:

```bash
python src/main.py
```

Входные адреса лежат в `data/input/addresses.csv`. Ключ и файлы из `data/output/` в репозиторий не добавляются
